# 07 辞書による最長一致分割  (目標 20分 / ★★)

日本語は単語の間に空白がないため、単語分割 (分かち書き) が必要です。
最も素朴な手法である **最長一致法** を、前向き・後ろ向きの2通り実装してください。

## 仕様
### `segment(text: str, dictionary: Iterable[str]) -> list[str]`  (前向き最長一致)
- 先頭から順に、**現在位置から始まる辞書中の最長の単語** を切り出して進む
- 現在位置から始まる単語が辞書に1つもなければ、**1文字** を1単語として切り出す

### `segment_backward(text: str, dictionary: Iterable[str]) -> list[str]`  (後ろ向き最長一致)
- **末尾から** 順に、**現在位置で終わる辞書中の最長の単語** を切り出して進む (無ければ1文字)
- 戻り値は元のテキストの順序 (先頭 → 末尾) に並べて返す

### 共通
- `dictionary` は `list` や `set` で与えられる。重複や空文字列 `""` が含まれることがある (空文字列は無視)
- 結果は必ず `"".join(結果) == text` を満たす。空文字列なら空リスト
- テキスト長 n、辞書の最大語長 L に対して **O(n·L) 回程度の辞書引き** で動くこと
  (長さ10万文字のテキスト・数千語の辞書でテストされます)

## 例
```python
>>> d = ["すもも", "もも", "も", "の", "うち"]
>>> segment("すもももももももものうち", d)
['すもも', 'もも', 'もも', 'もも', 'の', 'うち']
>>> d = {"東京", "東京都", "京都", "都知事", "知事"}
>>> segment("東京都知事", d)
['東京都', '知事']
>>> segment_backward("東京都知事", d)
['東京', '都知事']
>>> segment("私はNLPを学ぶ", {"私", "は", "を", "学ぶ"})
['私', 'は', 'N', 'L', 'P', 'を', '学ぶ']
```
