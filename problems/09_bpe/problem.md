# 09 BPE (Byte Pair Encoding) の学習と適用  (目標 35分 / ★★★)

GPT や RoBERTa などのサブワード分割の基礎である **BPE** を実装してください。
コーパスから「マージ規則」を学習する関数と、学習したマージ規則で単語を分割する関数の2つを作ります。

```python
def train_bpe(corpus: dict[str, int], num_merges: int) -> list[tuple[str, str]]
def encode(word: str, merges: list[tuple[str, str]]) -> list[str]
```

## 仕様
### 単語の初期分割
- 単語は 1文字ずつのシンボルに分割し、末尾に単語終端記号 `"</w>"` を **1つのシンボルとして** 付ける
  - 例: `"low"` → `["l", "o", "w", "</w>"]`

### `train_bpe(corpus, num_merges)`
- `corpus` は `{単語: 出現頻度}` の辞書 (頻度は正の整数、単語は空白を含まない空でない文字列)
- 以下を `num_merges` 回繰り返す:
  1. 全単語について隣接シンボルのペアを数える。各単語内でのペアの出現回数 × その単語の頻度 を合計する
     - 隣接位置ごとに数える (重なりも数える)。例: `["a","a","a","</w>"]` では `("a","a")` は 2回
  2. 合計回数が最大のペアを選ぶ。**同点の場合はペア (タプル) を Python で比較して最小のもの** を選ぶ
     - `min(..., key=lambda p: (-回数, p))` のイメージ
     - `"<"` は英字より小さいので、例えば `("aa", "</w>") < ("aa", "aa")` である点に注意
  3. 全単語で、そのペアを連結した新シンボル (`a + b`) に置き換える。置き換えは各単語の **左から順に、重ならないように** 行う
     - 例: `["a","a","a","</w>"]` に `("a","a")` を適用 → `["aa","a","</w>"]`
- ペアが1つも無くなったら (全単語が1シンボルになったら) その時点で終了する
- 戻り値: 選んだペアのリスト (選んだ順)。長さは最大 `num_merges`

### `encode(word, merges)`
- `word` を初期分割し、`merges` を **先頭から順に** 1つずつ適用する (各マージは上と同じく左から順に、重ならないように全箇所を置換)
- 最終的なシンボルのリストを返す
- マージ規則に出てこない文字はそのまま1文字のシンボルとして残る
- `word` が空文字列なら `["</w>"]`

## 例
```python
>>> corpus = {"low": 5, "lower": 2, "newest": 6, "widest": 3}
>>> train_bpe(corpus, 3)
[('e', 's'), ('es', 't'), ('est', '</w>')]
```
1回目は `('e','s')`, `('s','t')`, `('t','</w>')` がいずれも 6+3=9回で同点 → 最小の `('e','s')` を選ぶ。
```python
>>> merges = train_bpe(corpus, 5)
>>> merges
[('e', 's'), ('es', 't'), ('est', '</w>'), ('l', 'o'), ('lo', 'w')]
>>> encode("lowest", merges)       # 学習コーパスに無い単語も分割できる
['low', 'est</w>']
>>> encode("xyz", merges)
['x', 'y', 'z', '</w>']
>>> encode("abc", [("b", "c"), ("a", "b")])   # 適用順が大事
['a', 'bc', '</w>']
```
