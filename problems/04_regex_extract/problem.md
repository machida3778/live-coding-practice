# 04 正規表現による日付抽出  (目標 15分 / ★★)

ニュース記事や議事録から日付を **抽出** したり **マスク** したりする処理を実装してください。

## 対象とする日付表記
| 形式 | 例 |
|---|---|
| `YYYY年M月D日` | `2024年1月5日`, `2024年01月05日` |
| `YYYY/M/D` | `2024/1/5`, `2024/01/05` |
| `YYYY-M-D` | `2024-1-5`, `2024-01-05` |

- 年は **ちょうど4桁**、月・日は **1〜2桁** (ゼロ埋めは有っても無くてもよい)
- `/` と `-` の形式では区切り記号が **統一されている** こと (`2024/1-5` は対象外)
- 数字の並びの途中から切り出さないこと:
  - 年の **直前が数字** の場合は対象外 (`12024/1/5`, `12024年1月5日`)
  - `/` `-` 形式で日の **直後が数字** の場合は対象外 (`2024/1/155`)
  - (`年月日` 形式は `日` で終わるので、その後ろに数字が続いても対象: `2024年1月5日10時` → OK)
- 数字が **全角** (`２０２４年１月５日`) の場合も対象。区切り記号 `/` `-` は半角のみ考慮すればよい
- **実在しない日付** (`2023年2月29日`, `2024/13/1`, `2024-4-31`, 月や日が 0 など) は対象外

## 仕様
### `extract_dates(text: str) -> list[str]`
- テキスト中の有効な日付を `"YYYY-MM-DD"` 形式 (ゼロ埋め) に変換し、**出現順** にリストで返す
- 同じ日付が複数回現れたら、その回数だけ含める

### `mask_dates(text: str) -> str`
- 有効な日付表記を `<DATE>` に置換した文字列を返す
- 実在しない日付の表記、および **日付以外の部分は一切変更しない** こと

## 例
```python
>>> extract_dates("会議は2024年1月5日、締切は2024/02/10です。")
['2024-01-05', '2024-02-10']
>>> extract_dates("2023-2-29 は無効、2024-2-29 は有効")
['2024-02-29']
>>> mask_dates("期間: 2024/1/5〜2024/13/1")
'期間: <DATE>〜2024/13/1'
```
