# 01 単語頻度ランキング  (目標 10分 / ★)

英語テキストの単語頻度を数え、上位 k 件を返す関数 `top_k_words(text, k, stopwords=None)` を実装してください。

## 仕様
- 単語は **英字の連続** (`[A-Za-z]+`) とする。アポストロフィや数字は区切り文字扱い
  - 例: `"don't stop 2023"` → `["don", "t", "stop"]`
- 大文字小文字は区別しない (すべて小文字にして数える)
- `stopwords` (小文字の単語の集合, `None` なら無し) に含まれる単語は数えない
- 戻り値: `(単語, 出現回数)` のタプルのリスト
  - 回数の **降順**。回数が同じ場合は単語の **辞書順 (昇順)**
  - 種類数が k 未満ならあるだけ返す。`k <= 0` なら空リスト

## 例
```python
>>> top_k_words("The cat and the hat. The CAT!", 2)
[('the', 3), ('cat', 2)]
>>> top_k_words("b a c a b", 3)
[('a', 2), ('b', 2), ('c', 1)]
>>> top_k_words("The cat and the hat", 2, stopwords={"the", "and"})
[('cat', 1), ('hat', 1)]
```
