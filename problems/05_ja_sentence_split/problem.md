# 05 日本語の文分割  (目標 15分 / ★★)

日本語テキストを文に分割する関数 `split_sentences(text: str) -> list[str]` を実装してください。
(要約・翻訳・文埋め込みなど、多くの NLP パイプラインの最初の処理です)

## 仕様
1. **改行** (`\n`) は常に文の区切り。まず行に分け、各行を独立に処理する (括弧の状態も行ごとにリセット)
2. 文末記号 `。` `！` `？` `!` `?` の直後で文を区切る。文末記号は直前の文に含める
3. 文末記号が **連続** する場合 (`！？`, `!!`, `。。。` など) は、まとめて1つの区切りとして扱う
4. **括弧の内側** にある文末記号では区切らない
   - 括弧は `「」` `『』` `（）` `()` の4種類で、**入れ子** もありうる
   - 余分な閉じ括弧は無視する (括弧の深さは 0 未満にならない)
   - 閉じられないまま行末に達した場合は、その行末で文を打ち切る (規則1)
5. 各文の前後の空白 (半角/全角スペース, タブ) を取り除き、空になった文は除外する
6. 文末記号で終わらない末尾部分も1文として返す

## 例
```python
>>> split_sentences("今日は晴れ。明日は雨！本当？")
['今日は晴れ。', '明日は雨！', '本当？']
>>> split_sentences("彼は「はい。わかりました。」と言った。次へ。")
['彼は「はい。わかりました。」と言った。', '次へ。']
>>> split_sentences("えっ！？嘘でしょ!!")
['えっ！？', '嘘でしょ!!']
>>> split_sentences("一行目\n二行目。三文目")
['一行目', '二行目。', '三文目']
```
