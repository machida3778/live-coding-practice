# 03 テキスト正規化  (目標 15分 / ★★)

SNS投稿や問い合わせ文などの実データを機械学習に入れる前の前処理関数
`normalize(text: str) -> str` を実装してください。

## 仕様
次の処理を **この順番で** 適用した文字列を返してください。

1. Unicode 正規化 **NFKC** を適用する (全角英数字→半角, 半角カナ→全角カナ, 全角スペース→半角 など)
2. 英字をすべて **小文字** にする
3. **URL** を `<URL>` に置換する
   - URL = `http://` または `https://` で始まり、その後に次の文字が **1文字以上** 続く部分
     - 英小文字 `a-z`、数字 `0-9`、記号 `- . _ ~ : / ? # @ & = + %`
   - 日本語・空白・上記以外の記号は URL に含めない
     (例: `詳細はhttps://example.com/a?b=1を参照` → `詳細は<URL>を参照`)
4. **メールアドレス** を `<EMAIL>` に置換する
   - メールアドレス = `ローカル部@ドメイン`
   - ローカル部: `a-z 0-9 . _ + -` からなる1文字以上
   - ドメイン: `a-z 0-9 -` からなる1文字以上のラベルを `.` で **2つ以上** つないだもの
     (例: `example.com`, `mail.co.jp`)
   - `@user` や `a@b` のように条件を満たさないものは置換しない
5. 連続する **数字** (`0-9` の1文字以上) を `0` 1文字に置換する
   (例: `1,980円` → `0,0円`, `3.14` → `0.0`)
6. 連続する **空白文字** (半角スペース・タブ・改行など) を半角スペース1つにする
7. 先頭と末尾の空白を取り除く

※ 手順2のあとで置換するので、`<URL>` `<EMAIL>` は大文字のまま残ります。

## 例
```python
>>> normalize("Ｈｅｌｌｏ　ＷＯＲＬＤ！！")
'hello world!!'
>>> normalize("詳細はhttps://example.com/a?b=1を参照")
'詳細は<URL>を参照'
>>> normalize("連絡先: Taro.Yamada@Example.COM まで")
'連絡先: <EMAIL> まで'
>>> normalize("価格は１，９８０円\n\n（税込）")
'価格は0,0円 (税込)'
```
