# 14 BM25 による文書ランキング  (目標 25分 / ★★)

検索エンジンの定番スコア **Okapi BM25** を実装し、トークン化済み文書群のランキングを行うクラス `BM25` を作ってください。
(外部の BM25 ライブラリは使用禁止)

## 仕様
```python
class BM25:
    def __init__(self, docs: list[list[str]], k1: float = 1.5, b: float = 0.75): ...
    def idf(self, term: str) -> float: ...
    def score(self, query: list[str], i: int) -> float: ...
    def search(self, query: list[str], k: int) -> list[tuple[int, float]]: ...
```
- `docs` は1件以上あり、少なくとも1件は空でない (空の文書が混ざることはある)
- 記号
  - `N`: 文書数 (空の文書も数える)
  - `df(t)`: 単語 `t` を含む文書数
  - `f(t, d)`: 文書 `d` における `t` の出現回数
  - `|d|`: 文書 `d` のトークン数、`avgdl`: 全文書 (空の文書も含む) の `|d|` の平均
- `idf(term)`: `ln( (N - df(t) + 0.5) / (df(t) + 0.5) + 1 )` (自然対数)
  - コーパスに無い単語も `df = 0` としてこの式で計算する
- `score(query, i)`: 文書 `docs[i]` のクエリに対するスコア

  ```
  score(q, d) = Σ_{t ∈ q} idf(t) * f(t,d) * (k1 + 1) / ( f(t,d) + k1 * (1 - b + b * |d| / avgdl) )
  ```
  - クエリ中で重複する単語は **重複した回数だけ** 加算する
- `search(query, k)`: `(文書index, スコア)` のリスト
  - スコアの **降順**、同点は文書 index の **昇順**
  - スコアが `0` の文書 (クエリ語を1つも含まない文書) は含めない
  - 上位 `k` 件まで。`k <= 0` なら空リスト
- `search` / `score` は何度も呼ばれるので、文書ごとの単語頻度などは `__init__` で前計算しておくこと
  (大きめのコーパスでの実行時間テストがあります)

テストでは浮動小数点を許容誤差 `1e-9` で比較します。

## 例
```python
>>> docs = [
...     ["the", "cat", "sat", "on", "the", "mat"],
...     ["the", "dog", "sat"],
...     ["cats", "and", "dogs"],
...     ["the", "cat", "and", "the", "dog"],
... ]
>>> bm = BM25(docs)
>>> bm.idf("cat")          # ln((4 - 2 + 0.5) / (2 + 0.5) + 1) = ln(2)
0.6931471805599453
>>> bm.idf("bird")         # df = 0
2.302585092994046
>>> [round(bm.score(["cat"], i), 4) for i in range(4)]
[0.5848, 0.0, 0.0, 0.6422]
>>> bm.search(["cat", "dog"], 3)
[(3, 1.2843054026723784), (1, 0.7988814962385811), (0, 0.5847891845915171)]
```
(文書2 の `cats` / `dogs` はクエリ語と一致しないのでヒットしない点に注意)
