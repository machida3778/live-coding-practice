# 23 【模擬本番】日英混在ミニ検索エンジン  (目標 60分 / ★★★★)

日本語と英語が混ざった文書を対象に、BM25 でランキングする小さな検索エンジンを作ります。
パートごとにテストがあるので、**前から順に** 動くものを積み上げてください (部分点あり)。

---
## Part 1: 正規化とトークン化 (関数)

### `normalize(text) -> str`
- `unicodedata.normalize("NFKC", text)` の後に小文字化 (全角英数→半角, 半角カナ→全角 などが起きる)

### `tokenize(text) -> list[str]`
`normalize(text)` した文字列を先頭から見て、次の 2 種類の「連続部分 (ラン)」を出現順に取り出す。
それ以外の文字 (空白・記号・句読点など) は区切りとして捨てる。
- **英数字ラン**: `[a-z0-9]+` → ラン全体を 1 トークン
- **日本語ラン**: 次の文字の連続 → **文字 bigram** に分割 (長さ 1 のランはその 1 文字をトークンにする)
  - `々` (U+3005), ひらがな U+3041–U+3096, カタカナ U+30A1–U+30FA, 長音符 `ー` (U+30FC), 漢字 U+4E00–U+9FFF
  - (中黒 `・` U+30FB は含まない)

```python
>>> tokenize("東京タワーとTokyo Tower 2024年")
['東京', '京タ', 'タワ', 'ワー', 'ーと', 'tokyo', 'tower', '2024', '年']
```

---
## Part 2: 転置インデックス (`class SearchEngine(k1=1.5, b=0.75)`)
- `add_document(text) -> int`: 文書を登録し、doc_id (0, 1, 2, ... の連番) を返す
- `postings(term) -> dict[int, int]`: トークン `term` を含む文書の `{doc_id: 出現回数 tf}`。無ければ `{}`
- `doc_length(doc_id) -> int`: 文書のトークン数 (`len(tokenize(text))`)

---
## Part 3: BM25 検索 `search(query, k=10) -> list[tuple[int, float]]`
- クエリを `tokenize` し、**重複を除いた** 各トークン t について次を足し合わせたものを文書 D のスコアとする

```
score(D) = Σ_t  IDF(t) * tf(t,D) * (k1 + 1) / ( tf(t,D) + k1 * (1 - b + b * |D| / avgdl) )
IDF(t)   = ln( 1 + (N - df(t) + 0.5) / (df(t) + 0.5) )
```
  - N: 文書数, df(t): t を含む文書数, |D|: `doc_length(D)`, avgdl: 全文書 (トークン 0 個の文書も含む) の平均 doc_length
- クエリトークンを 1 つ以上含む文書だけを対象に、`(doc_id, score)` を **スコア降順 (同点は doc_id 昇順)** で上位 k 件返す
- 文書が無い / クエリのトークンが無い / 該当文書が無い 場合は `[]`

```python
>>> e = SearchEngine()
>>> for d in ["東京タワーは港区にある電波塔です。", "東京スカイツリーは墨田区にあります。",
...           "Tokyo Tower is in Minato, Tokyo.", "大阪城は大阪市にある城です。"]:
...     e.add_document(d)
>>> e.postings("東京"), e.postings("tokyo"), e.doc_length(0)
({0: 1, 1: 1}, {2: 2}, 15)
>>> [(i, round(s, 4)) for i, s in e.search("東京タワー")]
[(0, 3.9101), (1, 0.6092)]
>>> [(i, round(s, 4)) for i, s in e.search("TOKYO")]
[(2, 2.0574)]
```

## Part 4: スニペット `snippet(doc_id, query, width=10) -> str`
検索結果の表示用に、クエリが現れる付近を切り出してクエリ部分を `【】` で囲む。
1. `text = normalize(文書)` (スニペットは **正規化後** の文字列から作る)
2. 強調する語 = `normalize(query)` の **ラン** (Part 1 の英数字ラン・日本語ラン。bigram に分割しない)
3. 各語の `text` 中の出現位置をすべて求め (単純な部分文字列一致、重なりも含む)、区間 `[start, end)` にする。
   **重なる、または隣接する区間は 1 つにまとめる**
4. 区間が 1 つも無ければ `text[:2*width]` を返す (`text` がそれより長ければ末尾に `…` を付ける)
5. 最初の区間を `[p, q)` として、ウィンドウ `[max(0, p - width), min(len(text), q + width))` を切り出す
6. ウィンドウに **完全に含まれる** 区間を `【` `】` で囲む (はみ出す区間は囲まない)
7. ウィンドウの前に文字が残っていれば先頭に `…`、後ろに残っていれば末尾に `…` を付ける

```python
>>> doc = e.add_document("東京タワーの営業時間は9時から23時までです。東京タワーは港区にあります。")
>>> e.snippet(doc, "東京タワー 営業時間", width=5)
'【東京タワー】の【営業時間】…'
>>> e.snippet(doc, "港区", width=3)
'…ワーは【港区】にあり…'
>>> e.snippet(doc, "スカイツリー", width=5)
'東京タワーの営業時間…'
```
